Verificando...

A senha não é salva em texto puro: o FinanSee guarda um derivado criptográfico local. Este bloqueio protege o acesso pela interface, mas não transforma o navegador em um cofre criptográfico.


Seus dados

Backup e privacidade

🔐 Seus dados financeiros ficam neste navegador.O FinanSee não envia salários, gastos, metas ou cofres para um servidor próprio. Faça backup regularmente para não depender de um único aparelho.

O backup exporta somente os dados financeiros da conta atualmente aberta. Ao importar, o conteúdo entra apenas neste perfil.

Zona de segurança

Limpar os dados mantém sua conta. Excluir o perfil remove conta, dados, PIN e configurações locais deste usuário.
