# FinanSee PWA v8

Finanças pessoais local-first, multiusuário no dispositivo e instalável como PWA.

## Destaques da v8
- Competência mensal em Início, Gastos, Rendas, Calendário e Relatórios.
- Checklist de contas pagas/pendentes/atrasadas e pendências carregadas para o mês seguinte.
- PIX Crédito de 1x a 10x com valor enviado, total cobrado, custo extra e percentual efetivo.
- Fontes de renda com estimativa e histórico do valor realmente recebido por mês.
- Carteira separada de Vale Alimentação com previsto, depositado, gasto e restante.
- Calendário visual com indicadores, painel do dia, feriados nacionais e datas estaduais/municipais manuais.
- Relatório mensal com impressão/Salvar como PDF pelo navegador.
- Tela inicial de instalação do PWA antes do login no primeiro acesso.
- Login local, perfis separados, PIN opcional, backup JSON, tema claro/escuro e funcionamento offline.

## Publicar no GitHub Pages
Envie o conteúdo desta pasta para a raiz do repositório e publique a branch `main` em `/ (root)`.

## Privacidade
Os dados financeiros permanecem no armazenamento local do navegador. Não existe sincronização em nuvem. Faça backups JSON regularmente.
